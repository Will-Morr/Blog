For some time, I've wanting to make an autonomous, robotic instrument. There are a number of remarkable self-playing instruments projects, but every one I've seen requires being carefully set up and tuned before playing. Even the computer controlled builds are usually calibrated by hand, sending different control signals and tweaking to find each note. This is very time intensive, and neccessitates either tuning ever single voice separately or making rough approximations. by using closed loop audio feedback we can theoretically build any roboticized acoustic output and control it. This is my first attempt at this.
